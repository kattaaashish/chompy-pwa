Chompy — Quick Start
Kids' meal logging · Snap their meals. Know their nutrition.

📱 Set up Chompy on iPhone

Chompy is a web app (PWA) — no App Store needed. You install it straight from Safari.

  1. Open Safari (must be Safari, not Chrome) and go to https://chompy-pwa.ak-projects.workers.dev
  2. Tap the Share button (the square with an up-arrow).
  3. Scroll down and tap Add to Home Screen → Add.
  4. Launch Chompy from your home screen — it opens full-screen like a native app.
  5. Sign in: enter your phone number, then tap send — you'll be asked for a 6-digit code.
  6. Default OTP: 123456 — this master code works for any phone number (SMS isn't wired up yet). Enter it to log in.
  7. First time only: fill in the child's profile (name, age, etc.) so nutrition targets are personalized. You're in.
Allow notifications if you want meal reminders. Updates are automatic (it's a PWA) — no reinstalling. The code 123456 is a shared dev password: anyone with it can sign into any number, so don't post the link + code publicly.

Chompy — ChatGPT Integration
Read-only access to the food log via MCP + OAuth

🤖 Connect Chompy to ChatGPT

Chompy runs a read-only MCP server, so ChatGPT can search and read your child's food log — view-only, no writes.

  1. In ChatGPT, open Settings → Connectors. (Requires a plan/mode that allows custom connectors — Pro, Business/Enterprise, or Developer mode.)
  2. Add a custom connector and enter the MCP URL:
    https://chompy-pwa.ak-projects.workers.dev/mcp
  3. ChatGPT auto-discovers the OAuth server and opens a login page.
  4. Enter your phone number, then the OTP. Default OTP: 123456 (same master code as the app).
  5. Authorize — the connector links to that family's log.
  6. In a chat (or Deep Research), enable the Chompy connector and ask e.g. "What did my child eat today?" or "Which nutrients are low this week?"
What it can read: profile, meals, meal photos, daily/weekly nutrition summaries, and dinner recommendations. There are no write tools — ChatGPT can't log or change anything. The same /mcp URL + OTP also works in other MCP clients (e.g. Claude Desktop).
Security note (dev state): this MCP endpoint is public and auto-discoverable, and the 123456 master OTP verifies any phone — so anyone who reaches it could mint a read token to a family's whole log & photos. Fine for testing; lock it down (real SMS, token revocation, rate limiting) before real users.
